# Credits and licences

Every asset in this repository that was not generated by it, with a licence somebody checked.

## Fonts

Both are downloaded from Google's own font repository by `tools/design-extract/fonts.mjs`,
which records a SHA-256 of each file in `design/fonts/SOURCES.json`. The licence text is
committed **beside** the font, not linked: OFL 1.1 clause 2 requires the notice to travel with
the font files, and a URL in a README does not satisfy it.

|---|---|---|---|---|
| **Ranchers** | Every display heading, score and badge | SIL Open Font License 1.1 | © 2012 Pablo Impallari, © 2012 Brenda Gallo. Reserved Font Name *Ranchers* | [google/fonts `ofl/ranchers`](https://github.com/google/fonts/tree/main/ofl/ranchers) |
| **Hanken Grotesk** | Body copy, labels, all lowercase text | SIL Open Font License 1.1 | © 2021 The Hanken Grotesk Project Authors | [google/fonts `ofl/hankengrotesk`](https://github.com/google/fonts/tree/main/ofl/hankengrotesk) |

Licence texts: `design/fonts/Ranchers-OFL.txt`, `design/fonts/HankenGrotesk-OFL.txt`.

Both are the fonts the design reference itself specifies, so nothing was substituted. Had one
been unlicensable the substitution would be recorded here; none was needed.

**Reserved Font Name.** Ranchers carries one. The TTF is embedded unmodified and the TextMeshPro
SDF asset generated from it is named `Ranchers-SDF`, which is a description of the derived asset
rather than a renamed font, and the original file ships alongside. Do not rename the TTF.

## Icons

The eleven ingredient icons and the vector marks come from `design/design-reference.html`, which
is this project's own design document. They are extracted, not downloaded, by
`tools/design-extract/icons.mjs` — see `design/icons/index.json` for the uuid-to-name mapping.

## Audio

**All sound is synthesised in C# at runtime** (`unity/Assets/IsItDoneYet/Audio/ToneBank.cs`).
Nothing is sampled, nothing is downloaded, and there is therefore nothing to licence. That was
the reason for the decision as much as the zero-asset footprint was: at a hackathon, the audio
file whose licence nobody can produce is the one that gets the project disqualified.

If a real clip is ever added it goes in this table first, and it must be CC0 or original.
